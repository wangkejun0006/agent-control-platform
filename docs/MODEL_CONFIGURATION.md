# 可选真实模型配置

公开演示和测试默认离线，无需任何模型账号或密钥。模型配置存在不等于授权调用：只有显式预算Campaign才可通过唯一预留入口运行；失败和未知用量保留计数，无自动重试，不恢复旧额度。本轮发布收尾调用0次。

已验证的历史供应商适配为DeepSeek聊天接口；它不代表通用多供应商兼容性。需要新的真实验证时，先明确请求上限、费用和隔离活动，再单独授权，不直接复制历史CLI授权参数运行。

凭据通过`ORBIT_MODEL_CREDENTIAL_FILE`指定仓库外绝对路径的私有文件，只读取其中DEEPSEEK_API_KEY一项。权限必须仅当前用户可读写（0600），不接受符号链接、共享硬链接或其他用户拥有的文件。不要将该文件写入仓库、报告、环境示例或命令行参数。口令原文只在获授权的供应商传输内存出现。

代理通过`ORBIT_MODEL_PROXY`明确选择：`direct`表示直连，或指定`http://127.0.0.1:端口`、`http://localhost:端口`。不继承系统任意代理或带认证URL。保留TLS验证、拒绝重定向。

为了保留旧本机活动兼容性，未指定配置时仍使用用户目录`.hermes/.env`和本机7897代理；这不是新用户的必需环境。导入模块、查看页面、默认工作台和离线测试不会读取该文件。相关新配置仅做离线契约验证，本轮未进行新真实网络验证。
