# 已交付隔离案例的独立本机入口

地址：<http://127.0.0.1:8433/>。现有工作台仍是<http://127.0.0.1:8432/>，未切换或覆盖其数据库、账号和会话。

新入口是已完成案例的只读证据页，不启动完整工作台、数据库、身份服务、Worker或模型服务。它读取`.runtime/snapshot-delivery-20261017/`中的最终快照、验证报告及原交付ZIP；市场v1从该快照的历史候选读取，市场v2从当前候选读取。报告必须成功、交付状态必须完成，ZIP摘要与市场载荷必须匹配，否则拒绝启动。

页面提供：

- **返工前后**：显示市场v1原文与v2原文；v1明确标记离线初稿，v2标记既有真实模型候选，可展开摘要、来源定位及工具证据。
- **审核记录**：展示产品/技术批准、市场v1退回意见及市场v2批准，并可展开身份和绑定摘要。明确是合成本机测试账号审核，不是用户真人或生产批准。
- **交付文件**：列出三部门说明、三份引用和工具证据、审核及交付记录，下载原ZIP或零模型审核报告。下载ZIP字节与此前交付完全一致。

页面仅接受读取请求，其他方法返回405；没有任意文件路径接口，无登录Cookie、模型入口或执行操作。仅绑定127.0.0.1，拒绝外部Host，禁用脚本与外部资源。正文先HTML转义再渲染有限Markdown，不执行其中的HTML。虚构案例只供本机查看，未公开。

## 启停

在独立脱敏项目目录运行：

```bash
uv run --locked --offline python -m showcase.workbench.snapshot_view --port 8433
```

本轮已经后台启动，PID记录为`.runtime/snapshot-view-20261017/process.json`，日志为同目录`server.log`。端口占用时不要重复启动；停止前先核对PID对应的完整命令，只停止本入口进程，不影响8432。

服务不注册开机启动；电脑或WSL重启后可用上述命令重新打开。启动时缓存经过校验的只读快照，不跟随其他工作台任务变化。

本轮新增模型调用0次，不读取供应商密钥或任何旧预算；旧失败报告、已交付快照和ZIP未改写。验证见`reports/snapshot-view-validation-20261017.json`。5项离线测试覆盖真实案例只读重现、下载字节一致、HTML转义、写入/任意文件/外部Host拒绝、篡改与符号链接拒绝；浏览器确认页面展示及审核导航可用。
